# BookYourSeat

A team-built office booking application developed during the IT Smart Systems Summer School in 2026. The project brings room reservations, invitations and workplace planning into one web application.

## Tech stack

- Frontend - React, TypeScript, Vite
- Backend - Java, Spring Boot, REST APIs
- Database - PostgreSQL
- Design and collaboration - Figma, Git
- Testing - frontend UI checks, functional scenarios and API testing

## Features

- User authentication and account management
- Browse rooms and filter by building and floor
- Create and manage reservations
- Send and manage invitations
- View workplace information and commute-related widgets

## My contribution

I contributed to the UI/UX design and frontend planning, with a focus on turning Figma designs into reusable component specifications. I also worked on frontend QA, documenting positive and negative test scenarios for authentication, reservations, dashboard components and other user flows.

This was a team project. The application and its backend were developed collaboratively, and this repository does not represent solely my individual work.
